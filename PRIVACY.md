# Privacy policy

Tab Position runs locally in Chrome. It uses tab IDs, positions, window IDs, and pinned state only to rearrange tabs when you use a shortcut. It does not read page content, titles, URLs, or browsing history, and it sends no data to external services.

The swap preference is stored on your device using Chrome's local extension storage and is removed when you uninstall the extension. There are no accounts, analytics, advertisements, or data sales. Use of Chrome API information follows the Chrome Web Store User Data Policy, including Limited Use requirements.

For questions, open a [GitHub issue](https://github.com/gysi/chrome-extension-move-tab/issues). Issues are public; do not include sensitive information.
